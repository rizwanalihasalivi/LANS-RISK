The framework uses the requested black-and-white control-block style with actual LANS-RISK components. The main delay table covers all 12 controllers at 0, 200, 500, 700 and 1,000 ms; cells show mean RMSE and corridor-completed/total. All 44,000 main-confirmation records are represented. The main figure gives each controller its own panel. No intermediate delays were fabricated. Twenty cited references, literature comparison and detailed method equations are retained.

Verified 1,320 metric means, 300 aggregate/scenario delay-table cells and 88 empirical delay endpoints. The ZIP includes full scenario figures and source/data provenance. Dedicated robustness, observation-delay and runtime studies remain outside this conference article. Original V1 and V2 files are preserved. The seven-page limit applies to the main PDF; Word is an editing layout and supplemental documents are separate.
