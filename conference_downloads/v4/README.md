The ZIP includes the manuscript source, editable document, all main/scenario figures and tables, 44,000 main-confirmation episode records, processed CSVs, unchanged code excerpts, actor metadata, validation and review reports. It is the conference revision package, not a replacement for the full project code/model/checkpoint archive. Previous versions remain preserved.

The framework follows the supplied reference's spatial layout using implemented LANS-RISK blocks. ARIS reviewed the entire paper, source, figures and raw evidence. Numerical comparisons reconcile; remaining scientific limits and same-family/provisional review assurance are stated in ARIS_REVIEW.md. No publication acceptance is claimed. Full prompts/call traces remain local per the ARIS privacy rule.

All 20 references remain cited. All 12 controllers and measured command delays 0, 200, 500, 700 and 1,000 ms remain included. No values were invented at intermediate delays. Frozen experiments were not changed or rerun.
